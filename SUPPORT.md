# SafeSeed support

SafeSeed is a free, MIT-licensed open-source project. Support is public and best effort.

## Questions and bugs

Search [existing issues](https://github.com/advokat-frida/safeseed/issues) first. If the problem is
new, open an issue with:

- the SafeSeed version, or the full GitHub Action commit SHA;
- your operating system and Node version when using the CLI or library;
- the smallest command, workflow, schema, or structurally fake fixture that reproduces it;
- the complete error and exit code; and
- what you expected instead.

Never post production data, credentials, or real personal information. Replace them with obvious
test tokens or SafeSeed-generated values before sharing a reproducer.

## What belongs elsewhere

- Suspected vulnerabilities: use [private vulnerability reporting](https://github.com/advokat-frida/safeseed/security/advisories/new), not a public issue.
- Legal or compliance conclusions: SafeSeed is a technical control and teaching tool, not legal advice or a substitute for your own assessment.
- General product background and the interactive demo: [advokatfrida.com/safeseed](https://advokatfrida.com/safeseed/).

There is no guaranteed response time, private implementation consulting, or compatibility promise
for unsupported releases.
